# ZERO

無料API、自動準備する端末内LLM、Google Apps Script（GAS）、非公開Googleスプレッドシートで動く日本語の会話型アシスタント。通訳君を参考にした黒基調の操作画面です。有料の推論APIは使いません。

## 構成

GitHubでソースを管理し、GitHub PagesからGASのWebアプリを表示します。GASのHTML画面から `google.script.run` を呼び出す構成により、クロスオリジンの保存APIにJSONPやno-corsを使う必要がありません。埋め込みが制限されるブラウザでは「別画面で開く」を使います。

- `index.html`：GitHub Pagesの入口
- `config.js`：GASの公開URL（秘密鍵は含みません）
- `App.html`：GASが表示する画面と会話処理
- `Code.gs`：API取得、利用制限、データベース処理
- `Config.gs`：データベースのファイルID。ファイル自体は非公開のまま利用
- `appsscript.json`：GAS実行設定
- `preview.html`：GAS未接続でも実データ取得を試せる画面。履歴は保存しません

## データベース

| シート | 用途 |
| --- | --- |
| Settings | アプリ名、見出し、履歴保存の有効・無効 |
| Providers | 利用するAPIの有効・無効、ライセンス、出典 |
| Conversations | 会話ID、所有者ハッシュ、題名、日時、会話条件 |
| Messages | メッセージID、所有者ハッシュ、会話ID、発言、日時、出典 |

各シートの1行目は列名です。列名・順序を変更するとGASは処理を停止します。

## 利用できる機能

天気の取得と最大3都市の比較、服装の目安、日の出・日の入り、通貨換算、Wikipedia本文抜粋、書籍検索、生命科学文献、USGSの重要地震、World Bankの首都・人口、Hacker Newsの技術記事、日本の祝日、計算、世界時計。続く質問に都市や日付、書籍・文献の検索条件を引き継ぎます。「できること」で用途を検索できます。端末内モデルを読み込むと、文章作成・翻訳・要約・コードの説明も試せます。

## 端末内LLM

アプリを開くと、全4モデルを順番に読み込んで準備します。初回はモデル合計約2.7GBに加え、実行ファイルを取得します。実行は1モデルずつ行い、準備後は標準のQwen3-1.7Bを起動します。「端末内AI」で4モデルの準備状況を確認し、準備済みの別モデルを選んで「選択したモデルを起動」で切り替えられます。ブラウザーが保持している取得済みファイルは再利用します。

一括準備中もAPI照会・計算を使えます。LLM生成は準備終了後に利用します。「一括準備を停止」または入力欄の「停止」で中断すると、停止設定を保存し、再読込時に勝手に再開しません。「全モデルをまとめて準備」で再開します。GPU非対応端末ではGPUモデルを未対応と表示し、CPU互換モデルを準備します。別の端末・ブラウザーではそれぞれ初回取得が必要です。

一般的な質問は従来のAPI・計算処理を優先し、`文章: お礼メールを作成`、`翻訳: ここに文章`、`要約: ここに文章`、`コード: JavaScriptの配列を説明`で生成を指定できます。モデルが利用可能なら、対応するAPI処理のない依頼にも生成で応答します。

| 選択肢 | 用途 | モデルの取得量の目安 | 実行方式 |
| --- | --- | --- | --- |
| Qwen3-1.7B | 会話・文章の標準候補 | 985 MB | WebGPU |
| Qwen3-0.6B | 軽量な短文。日本語の品質には限界あり | 352 MB | WebGPU |
| Qwen2.5-Coder-1.5B | コード相談 | 881 MB | WebGPU |
| Qwen2.5-0.5B | 互換モード。英語の短文向け。日本語・翻訳は不得手 | 約520 MB | CPU / WASM |

すべて元モデルはApache-2.0です。変換済みモデルを公開リポジトリの固定リビジョンから取得し、WebLLM 0.2.85 / Transformers.js 3.8.1を使用します。ライセンス本文・提供元は[MODEL_NOTICES.txt](MODEL_NOTICES.txt)を参照してください。1モデルずつ読み込み、停止・読み込み解除でWorkerを終了します。途中で停止・失敗した生成文は「未完」と明記して残し、次の生成用の会話条件には加えません。再開にはモデルを再読込します。コードを自動実行しません。

料金を請求する推論サービスへの接続はありません。通信量、電力、端末容量は利用します。WebGPUの対応、GPUメモリ、ブラウザのWASM制限などにより、すべての端末での動作は保証できません。CPUモードも遅い端末や容量不足では利用できません。GPUメモリ目安はダウンロード量や端末の総必要RAMとは別です。ブラウザのキャッシュは再利用される場合があり、解除してもファイルを削除しません。

生成中は入力を外部の推論サーバーへ送りません。ただしGAS接続時は、生成への質問・回答も通常の会話履歴として管理者のスプレッドシートに保存します。APIの本文や過去のAPI回答をモデルへ自動投入せず、LLMの短い会話履歴だけを引き継ぎます。特にopenBD等の原文表示が必要なデータを勝手に書き換えません。最新情報・計算はデータ照会で確認し、生成文には誤りがあり得ます。

1回の生成はGPUで最大384トークン、CPUで最大160トークンです。文字数とは異なります。上限到達・終了理由不明を画面で知らせ、未完の出力を次回の生成条件へ加えません。Qwen3では反復を抑えるサンプリング設定を使い、14〜120文字の同じ表現が末尾で4回連続した場合は停止して原文と理由を残します。明示的な反復依頼やコードブロックにはこの停止を適用しません。反復の完全な防止や、依頼の全条件を満たす文章品質を保証するものではありません。文章作成・翻訳・要約は用途別の指示を補い、翻訳本文の全角文字や記号は書き換えずに渡します。

## 端末内でできること

- 単位換算：`5kmは何マイル？`、`1ポンドをkgに換算`、`32°Fは何℃？`。長さ・常衡質量・面積・体積・温度に対応します。フィート・マイルは国際定義を用い、ガロンなど定義の紛らわしい単位は含めません。表示は最大13桁に丸めます。換算後の`cmなら？`は元の数量を引き継ぎます。
- 日付計算：`今日から100日後は何日？`、`2026/10/25の3日前`、`2026年10月25日は何曜日？`。
- 日数差：`2026-10-25から2027-01-01まで何日？`。開始日を0日として数えます。日付の「今日」は端末の時計による日本時間です。グレゴリオ暦の西暦1〜9999年を扱い、実在しない日付は自動補正しません。

## 営業日で計算する


`2026-10-30から3営業日後は何日？`、`今日から5営業日前は？`で、土日と日本の祝日を除いた前後の日付を計算します。開始日を0日として数え、0日後は休日でも開始日と同じ日付です。

`2026-10-01から2026-10-31までの営業日は何日？`は、両端の日付を含む期間内の営業日数を返します。同じ営業日だけなら1日、同じ休日だけなら0日です。日付を逆順で指定すると、同じ範囲の日数を負数で返します。通常の暦の日数差とは数え方が異なります。

祝日は[Holidays JP](https://holidays-jp.github.io/)の登録不要・MITの既存APIから取得し、取得済みデータを再利用します。提供元は前年・当年・翌年を収録します。年初の日付を含めてデータの形式を確認し、収録されていない年を平日として推測しません。会社独自の休業日や年末年始休業は加えません。例えば12月31日が平日で祝日でなければ営業日として数えます。除いた土日・平日の祝日の数と出典を表示します。

`土日のみ除く: 2026-10-30から3日後は何日？`なら、祝日を数え、土日のみを除外します。この指定は外部API・LLM不要です。前後の計算は1000日、期間の計算は3660日以内です。

単位換算と通常の暦の日付計算では外部APIを呼びません。GAS接続時の会話保存は通常どおり行います。換算係数の出典は[NIST Guide to the SI](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors)です。

## 条件を引き継ぐ通貨換算

`100万円は何ドル？`、`1.5億円をユーロに換算`、`USD 100をJPYに換算`のように、万・億の倍率とISO通貨コードの前置・後置を扱います。対応通貨はUSD/EUR/JPY/GBP/CNY/KRW/AUD/CAD/CHFです。金額は0〜1兆。万・億は数値に1つ付ける表記に対応し、`1億2000万円`のような複合表記は確認を促します。桁区切りの不正や負の金額を、別の数値へ読み替えません。

換算後の`200なら？`は通貨ペアを保って金額だけを変更し、`ユーロにすると？`は金額と換算元を保って換算先を変更します。`200ドルなら？`は金額と換算元を変更し、換算先を維持します。`逆にすると？`は同じ金額のまま通貨ペアを入れ替えます。`ユーロなら？`のように方向が曖昧な場合は確認を促します。まとめて質問した場合も、直前に成功した処理の条件を次の依頼に引き継ぎます。

レートには既存の[Frankfurterの無料公開API](https://frankfurter.dev/)を使用します。指定ペア・正の有限数・実在するレート日を検証し、最大12桁で概算を表示します。同じペアの取得済みレートを再利用し、同じ通貨の換算ではAPIを呼びません。両替・決済手数料は含まず、リアルタイム相場ではありません。

## 英国3地域の祝日

`2027年のイギリスの祝日`は、イングランド・ウェールズ／スコットランド／北アイルランドを分けて表示します。`スコットランドの次の祝日は？`は英国時間の当日を含む、今後の先頭3件です。「スコットランドなら？」は年・一覧／次の条件を維持し、「来年は？」は英国の現在年から翌年を求めて年別一覧に切り替えます。「日本の祝日」は既存の日本向けデータを使います。

[英国政府の公開API](https://www.api.gov.uk/gds/bank-holidays/)の固定JSONのみを取得します。登録・キー不要、© Crown copyright / [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/)で商用・非商用に無償利用できます。提供元・ライセンスを表示し、名前と振替日の注記は原文のまま表示します。取得済みデータは最大1時間再利用します。

Bank holidayは銀行休業日の登録情報で、店舗・学校・勤務先すべての休業を表すものではありません。取得できた年だけ回答し、未収録年や範囲末尾から将来の日付を補いません。各年の一覧は地域ごと最大24件。月日指定・英国の営業日計算には未対応で、条件を黙って無視せず案内します。未対応国の祝日を日本の祝日に置き換えません。

## 分野をまたぐ学術検索

`学術検索: quantum computing`、`学術検索: education`で、Crossrefに登録された学術資料を検索します。1ページ3件、先頭から最大5ページです。「学術検索の続き」で同じ検索語の次ページへ進みます。既存の`論文: sleep`は引き続き生命科学中心のEurope PMCを使用します。

`DOI: 10.1038/nphys1170`または`https://doi.org/10.1038/nphys1170`で、Crossrefに登録された識別子の書誌を確認できます。他の登録機関のDOIや、一部の記号を含むDOIには未対応です。取得項目はDOI・タイトル・著者・刊行日・掲載媒体・資料種別の6項目に固定し、抄録・本文・引用文献は取得対象に含めません。

論文・会議論文・書籍章・投稿資料等を区別し、日付は提供元の精度のまま表示します。月しか登録されていない場合に1日を補いません。DOIは資料の識別子であり、査読済み・内容の正しさ・無料の本文へのアクセスを保証しません。

利用する[Crossrefの公開REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)は無料・登録不要です。GASでは全利用者を通じて同時照会1件、取得完了後1.1秒以上の間隔を設けます。別の照会中は案内して停止し、自動再試行しません。429/503では既存の待機・キャッシュの仕組みを使います。有料のMetadata Plusや推論APIには接続しません。

## 保存とアクセス

GAS接続時は質問・回答・会話条件を保存します。ブラウザ内で作った256ビットのランダムな識別情報をリクエストごとに送信し、サーバーではSHA-256ハッシュとして照合します。他の利用者の会話一覧・本文は返しません。同じブラウザ・プロファイルを共有する人は同じ履歴にアクセスできます。ブラウザデータを削除した場合や、ブラウザが埋め込み画面のストレージを制限した場合、過去の履歴に再接続できないことがあります。この識別方式はGoogleアカウント認証の代わりとなる機密データ保管の仕組みではありません。

スプレッドシートの管理者は保存された会話を閲覧できます。データベースの共有範囲は拡大しないでください。GASのWebアプリはデプロイしたユーザーとして実行します。公開URLには匿名アクセスを許可しますが、履歴の取得・保存は識別情報ごとに制限されます。

## 費用と制限

有料API、試用クレジット、カード登録が必要な接続先は使いません。料金を要求しない公開APIと端末内の処理を使い、負荷制限や利用条件に従います。上限時に課金へ切り替える処理はありません。詳細は `POLICY.md` と `providers.json` を確認してください。

1ブラウザ識別情報につき毎時120リクエスト、アプリ全体で1日1000件の外部API新規取得、1会話100発言、1利用者50会話、各データシート20000行をアプリ側の負荷保護上限としています。購入クレジットではありません。GitHub・GAS等にも実行・容量の上限があり、無制限の稼働は保証しません。API応答をキャッシュして負荷を抑えます。

## 通信と表示

複数の依頼は「それと」「そして」、改行、句点、セミコロンで区切って送れます。例：`5kmは何m？それとcmなら？そして今日から100日後は何日？`。前の処理の結果で会話条件を更新してから、次の依頼を解釈します。本の題名などに区切りの語を含む場合は`本:「昨日。そして明日」`のように引用してください。引用・括弧内は分割しません。1回の実行は4件までで、残りや未対応の依頼は案内します。

提供元がHTTP 429または503を返した場合は、接続先ごとに新しい照会を停止します。`Retry-After`の秒数・日時指定を優先し、指定がなければ通常60秒、辞書の429では次のUTC正時まで待機します。GAS側は利用者間で待機期限を共有します。期限内でも有効なキャッシュや端末内処理は利用できます。自動再試行や別の接続先への切り替えは行いません。

現地の時間帯を未登録の都市は、天気・天文の日付と時刻をUTC基準と明示します。世界時計は登録済みの時間帯だけで回答します。回答完了後は会話欄を結果の末尾までスクロールします。

## 更新

GASに `Code.gs`, `Config.gs`, `App.html`, `appsscript.json` を反映し、既存デプロイを新しいバージョンへ更新します。`config.js` のURLを維持すればGitHub Pagesの入口はそのまま使えます。画面を編集するときは `App.html` とプレビューを同じ状態に保ってください。

初回は所有者によるGoogleの権限承認が必要です。必要な権限はスプレッドシートへの読み書きと外部サービスへの通信です。

## API出典

郵便番号からの住所検索は`〒100-0014`、`郵便番号: 0790177`、`1000014の住所は？`のように指定します。7桁と先頭の0を検証し、複数の住所候補を最大20件表示します。町域が未収録の場合はその旨を表示します。番地・建物などは別途確認してください。数字だけの入力を郵便番号として外部照会することはありません。再利用は最大1時間です。

ISBNによる本の紹介に対応しました。`ISBN: 978-4-7808-0204-7`、`ISBN-10: 4780802040`のように入力します。検査数字を確認してから照会し、書名・著者等・出版社などを提供元の表記で表示します。詳細は版元ドットコムの本紹介ページへ進めます。ISBNが正しくても、openBDに収録されていない本があります。結果の再利用は最大1時間です。情報の更新や削除要請がある場合は接続を停止し、保存済みの紹介データも管理者が確認して対応します。
